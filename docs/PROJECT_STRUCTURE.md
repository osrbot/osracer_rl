# 项目结构

| 路径 | 职责 | 是否属于公开演示 |
| --- | --- | --- |
| `OSRACER/` | ROS 车辆描述、传感器与控制接口 | 是；由工程文档说明 |
| `racing/` | 双车竞速、策略、安全层、审计与报告逻辑 | 是；源码与测试是复现依据 |
| `tracks/` | 24 条唯一赛道、两季来源与 RC/原尺度资产 | 是；来源与几何假设见 `TRACK_SOURCES.md` |
| `scripts/` | 环境检查、训练、批处理、录像、素材整理脚本 | 是；命令应在完整工程根目录执行 |
| `output/usability/` | OpenUSD / MuJoCo 资产加载、渲染、步进的原生验证 | 是；仅证明资产层可用 |
| `output/racing/` | 资格结果、轨迹、审计、视频、媒体索引和策略清单 | 是；大文件按需克隆/下载 |
| `presentation/` | 可编辑 PPTX 生成脚本、讲稿、媒体清单 | 是；构建产物可从静态站下载 |
| `docs/` | 工程、验证、发布、部署、直播和结构文档 | 是；静态站的主要信息来源 |
| `deploy/` | 车辆端 shadow 部署参考节点 | 是；不代表已实车上线 |
| `experimental/` | 被隔离的候选、失败对照或接触调查 | 仅作证据；不能混入冻结成绩 |
| `.loopx/`、`.codex/` | 本地目标状态和代理控制信息 | 否；已由 `.gitignore` 忽略 |

## 公开仓库边界

公开提交应包含源码、可复现实验配置、文档、精选验证媒体与已审计结果；不应提交本地虚拟环境、缓存、控制面状态、密钥、GPU 日志或未审查的大型训练中间产物。`.gitignore` 已覆盖常见本地状态；发布前仍需人工检查 `git status`。

## 从哪里开始

1. 阅读 [验证状态](VALIDATION_STATUS.md)，先理解结论与边界。
2. 查看 [冻结发布](RELEASE.md)，获取配置、成绩和复现命令。
3. 打开 [直播材料](LIVE_BRIEFING.md) 或静态站首页浏览视频。
4. 需要部署时，再阅读 [实车部署](DEPLOYMENT.md)，按 shadow → 台架 → 低速流程推进。
